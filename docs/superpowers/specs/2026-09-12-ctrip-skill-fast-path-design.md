# 携程比价 Skill 快速路径设计

## 目标

用户提供酒店、城市、入住起始日和采集天数后，Skill 只进行一次参数准备和脚本调用。

## 行为契约

- 只追问缺失的必填字段：酒店、城市、入住起始日、采集天数。
- 成人数、儿童数、房间数、晚数、价格模式使用既有默认值，不因默认值追问。
- 参数齐全后直接写入一次性配置并调用 `collect --config` 。
- 不预先调用 `login-status` 、`setup` 或外部网页。
- 登录、浏览器启动、登录窗口、详情页搜索、零价复核和 Excel 导出由脚本负责。
- 只在脚本返回登录提示、参数错误或环境错误时进行对应处理。

## 非目标

本次不修改 Python 业务代码、安装器、浏览器启动逻辑或客户包结构。

## 验收

Skill 文档能让执行者在参数齐全时一次调用 `collect` ，并明确禁止前置登录检查、环境检查和外部搜索。
